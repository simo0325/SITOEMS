# Git Auto Sync Rule

Ogni volta che completi una modifica importante o su richiesta dell'utente:
1. Esegui il commit di tutti i file modificati con un messaggio chiaro e descrittivo.
2. Esegui il push direttamente sulla repository GitHub associata (`https://github.com/simo0325/SITOEMS.git`).
3. Assicurati che file con segreti o credenziali (es. `discord_bot_config.json`, `.env`) restino sempre protetti e ignorati nel `.gitignore`.
